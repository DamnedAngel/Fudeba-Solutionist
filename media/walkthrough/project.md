# Add a project

Run **New Project from Template...** to add a project to the open solution (or to create a solution and its first
project in one step).

It finds the templates installed for Visual Studio, plus folders you list in the setting
`fudebaSolutionist.templateFolders` and templates imported with **Import Project Template**. For the MSX templates
(ROM, MSX-DOS, BIN and overlay projects) the project's Config files are shown in the project settings dialog.
