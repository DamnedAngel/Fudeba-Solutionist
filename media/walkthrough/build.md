# Choose a configuration and build

The first row of the tree is the **configuration** (Debug or Release); click it to switch. Every build action follows it.

Build a project from its row, or the whole solution from the view's title bar. The output looks like Visual Studio's,
with an `N>` prefix per project and a summary at the end, and the errors land in the Problems panel with explanations
for SDCC, SDAS and ZOO messages.
