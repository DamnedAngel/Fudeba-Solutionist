# Create a solution

A **solution** groups the projects you work on together, as in Visual Studio.

Run **Create a New Solution...**: pick a folder, a name and the file format (`.sln` or `.slnx`). A folder with the
solution's name is created, with the empty solution file in it. It then opens in the **Fudeba Solutionist** view.

You can also start it from **File > New File...**.
